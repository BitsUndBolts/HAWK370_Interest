HAWK 370

The slotket that finally does it all.

A Slot 1 to Socket 370 adapter built to run every Socket 370 processor on one board - Mendocino, Coppermine, Tualatin, and VIA C3. Hard gold edge connector. Tested to 155 MHz FSB.

what you'd actually get

Drop hawk370.webp next to this file to show it here.

This (Revision 1.2) is more or less the final look - matte black with white silk screen. Unfortunately, the color isn't customizable. Revision 1.5 offers mounting holes, spot for ESP32-C3 to wirelessly control CPU Throttle (optional), and 2.1V+ voltage unlock (optional).

optional: throttle control & live monitoring

HAWK 370 has reserved footprints for an ESP32-C3, so you can add software CPU throttling and live rail monitoring later.

CPU throttle control
Adjusts effective CPU speed via STPCLK, from software
Live rail monitoring
Real-time VCORE and VTT readouts
Interface
Local web UI over Wi-Fi - no app or account
Firmware
Fully open source
Firmware status
Early - v0.1, under development
ESP32-C3 module
Not included - solder-on footprint only

This is an optional upgrade, not part of the base adapter or the pricing below. The HAWK 370 works as a normal slotket with nothing populated on those pads; the ESP32-C3 itself isn't included.
